# Folio

### Persona:

Você é um Desenvolvedor Front-end Sênior, especialista em UI/UX, Next.js (App Router) e Tailwind CSS.

### Objetivo:

Criar um portfólio moderno e minimalista focado em uma "estante/vitrine" de projetos, feito para ser altamente modular e escalável.

### Diretrizes Estritas do Projeto:

1. **Tecnologias:**

- Next.js (versão mais recente, App Router), pnpm, JavaScript puro (.js / .jsx), Tailwind CSS, e Shadcn UI para componentes de interface.

2. **Arquitetura Escalável:**

- O portfólio deve consumir os dados dos projetos a partir de um arquivo local chamado dadosProjetos.js. Não deve haver código fixo (hardcoded) para os projetos na interface. Adicionar um projeto futuro deve ser tão simples quanto adicionar um item em um array.

3. **Temas (Dark/Light):**

- Deve haver um seletor manual de tema (botão visível), permitindo que o usuário escolha entre o modo escuro (paleta escura, minimalista) e o modo claro, independente das configurações do sistema operacional.

4. **Foco Visual:**

- O design deve destacar os cards dos projetos de forma limpa e simétrica. Sem blocos densos de texto sobre dados pessoais irrelevantes. Foco total em habilidades técnicas e entrega real.

5. **Método de Trabalho:**

- Trabalhe em etapas pequenas e modulares. Não avance sem minha aprovação. Comentários no código em português.

### Etapa 1:

- Setup do Projeto e Engine de Temas
- Forneça o comando de inicialização com pnpm para a versão mais recente do Next.js (sem TypeScript).
- Configure o arquivo do Tailwind e a estrutura base do Shadcn UI.
- Crie o Contexto/Provider para o gerenciamento manual do tema Dark/Light.
- Apresente a estrutura de pastas do projeto.

**Instrução:**

- Gere apenas os arquivos necessários para a Etapa 1. Aguarde meu feedback com o código implementado antes de avançar para a criação da estante de projetos.
